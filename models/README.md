# Models Directory

This directory stores serialized model artifacts, trained checkpoints, encoders, and scaler pipelines.

## Planned Contents

- `forecasting/`: Trained demand forecasting models (e.g., scikit-learn models, time series baselines, weights).
- `scalers/`: Preprocessing pipelines and encoders for consistent inference.

## Guidelines

- Keep model files tracked or referenced according to hackathon size constraints.
- Provide clear naming conventions (e.g., `demand_model_<item_or_category>_v1.pkl`).
- Include evaluation metrics and training metadata where applicable.
